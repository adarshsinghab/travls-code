A luxury, ultra-responsive financial interface engineered for high-net-worth global spenders, corporate treasuries, and multi-currency crypto-fiat settlement.

## ✨ Key Architectural Features

### 1. 🎨 Dual-Theme Institutional Engine (WCAG AAA Compliant)
- **Obsidian Dark** (`obsidian`): Flagship dark luxury theme engineered with deep obsidian slate (`#070A0F`), matte card elevation (`#101724`), brushed gold accents (`#FFB91F`), and specular micro-borders.
- **Executive Light** (`executive`): Daylight luxury theme engineered with pure white cards (`#FFFFFF`), high-contrast slate typography (`#0F172A`), warm amber indicators (`#D97706`), and crisp `#E2E8F0` separation.

### 2. 💳 Theatrical 3D Card Cascade Stage
- **Physical & Virtual Metal Fleet**: Brushed Titanium Black, Mirror Platinum Silver, and Cyber Virtual.
- **Instant Controls & Security**:
  - Dynamic spend limit adjustment slider with real-time feedback ($1,000 – $30,000).
  - 30-second rotating CVV reveal countdown with auto-masking security.
  - One-tap instant card freeze toggle.
  - 3.5% auto-compounding cashback breakdown.

### 3. 📈 Financial Telemetry & Spend Wave
- Smooth SVG cubic bezier spend curve reflecting rolling authorizations.
- Interactive hover telemetry detailing merchant volume, date, and USD values.
- Clean institutional KPI metric bar (Treasury Balance, 30-Day Spend, Cashback Yield, Settled Fiat).
- Treasury asset allocation (USDT, BTC, ETH, SOL) with real-time valuation.

### 4. 📐 Engineered Layout & Ergonomics
- **Stay-in-Place Architecture**: Sticky top navigation bar and fixed sidebar with independent, inertia-smooth content scrolling.
- **Collapsible Navigation**: Seamlessly toggle between full 260px expanded menu and 74px compact icon-only mode with tooltips.
- **Responsive Views**: Complete workflows for Dashboard, Cards, Accounts & Deposits (with dynamic QR codes), Transfers (with Multi-Country Beneficiary flows), Transactions with drawer inspector, and KYC Verification.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/adarshsinghab/travls-code.git

# Navigate to the project directory
cd travls-code

# Switch to the main branch
git checkout main

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
# Type check and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
