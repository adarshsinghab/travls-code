## ✨ Key Architectural Features

### 1. 🎨 Multi-Theme Color Engine (Bespoke & WCAG AAA)
- **Obsidian Gold** (`obsidian`): Dark luxury flagship theme featuring deep obsidian tones (`#080A0E`), brushed champagne gold accents (`#C5A880`), subtle glow rings, and velvet glassmorphic elevation.
- **Midnight Cyber** (`midnight`): High-tech aerospace aesthetic featuring deep midnight navy (`#0B111E`), electric cyan luminescence (`#06B6D4`), and holographic telemetry accents.
- **Executive Light** (`executive`): Pristine daylight luxury theme built with pure white cards (`#FFFFFF`), high-contrast slate typography (`#0F172A`), warm amber indicators (`#D97706`), and zero dark-mode artifacts or bleed-through.

### 2. 💳 Theatrical 3D Card Cascade Stage
- **Interactive Physical Cards**: Brushed Titanium Black, Mirror Platinum Silver, and Cyber Virtual Cyan.
- **Instant Interactive Controls**:
  - Dynamic limit adjustment slider with real-time feedback ($1,000 – $50,000).
  - 30-second rotating CVV reveal countdown with auto-masking security.
  - One-tap Card Freeze toggle with cyan snowflake status indicator.
  - Live 3.5% APY crypto yield telemetry & automated billing toggle.

### 3. 📈 Real-Time Financial Telemetry & Spline Wave
- Smooth SVG cubic bezier spend curve reflecting weekly and monthly volume.
- Interactive hover nodes detailing timestamps, merchant categories, and USD values.
- Multi-currency crypto treasury breakdown (USDT, BTC, ETH, SOL) with live price tickers.
- Floating quick-action hub (`Transfer`, `Top Up / Swap`, `Card Settings`).

### 4. 📐 Engineered Layout & Ergonomics
- **Stay-in-Place Architecture**: Sticky top navigation bar and fixed sidebar with independent, inertia-smooth content scrolling.
- **Collapsible Navigation**: Seamlessly toggle between full 260px expanded menu and 74px compact icon-only mode with tooltips.
- **Responsive Views**: Complete workflows for Dashboard, Cards, Accounts & Deposits (with dynamic QR codes), Transfers (with Multi-Country Beneficiary flows), Transactions with drawer inspector, and KYC Verification.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/adarshsinghab/travls-code.git

# Navigate to the project directory
cd travls-code

# Switch to the main branch
git checkout main

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
# Type check and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
